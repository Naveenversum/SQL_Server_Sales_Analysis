# Sales Analysis – SQL Server

## Project Overview

This project focuses on analyzing sales data using Microsoft SQL Server and T-SQL.

The objective was to validate the sales data, perform data analysis using SQL queries, and identify useful business insights from the dataset.

## Tools Used

- Microsoft SQL Server
- T-SQL
- VS Code with MSSQL extension

## Dataset

The dataset contains approximately 50,000 sales records with information such as:

- Order ID
- Order Date
- Customer Name
- City
- State
- Product
- Category
- Salesperson
- Quantity
- Price
- Discount
- Total Sales
- Payment Mode
- Region

## Data Validation

The data was validated using SQL queries to check:

- Duplicate Order IDs
- Blank Order IDs
- Total Sales calculation
- NULL values
- Payment Mode values

A backup table was also created before performing data validation and analysis.

## SQL Analysis Performed

The project includes analysis of:

- Monthly Sales
- Highest Sales Month
- Sales by Category
- Sales by Salesperson
- Sales by City
- Sales by State
- Sales by Product
- Product Quantity
- Average Product Price
- Customer Sales
- Category Quantity
- Average Order Value (AOV)
- Top 5 Products by Quantity
- Top 5 Products by Sales
- Category Sales Contribution
- State and Category Sales
- Top 10 Customers by Orders
